## Initilize the Playwright

```
npx playwright init
```

## Command used for testing the playwright all files or specific file

```
npx playwright test / npx playwright test file_name
```

## Commands run with UI and trace

```cmd
npx playwright test --headed --trace on
```

#### and run the report

```
npx playwright show-report
```

## Command for running the challenge files

````
npx playwright test tests/challenges/challenge_file--headed --trace on
```
````
